work about

Mapping urban development in 4 popular tourist hotspots in Costa Rica from 2016 to 2025

This project uses Sentinel 2 images and a KNN model to classify urbanized areas of popular tourist locations in Costa Rica. OpenEO API is used to source the images and uses a Best Available Pixel (BAP) algorithm to mask out cloud cover.
